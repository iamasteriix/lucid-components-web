# Box

`Box` is the atomic layout primitive of the UI Kit. It is the single source of truth for all positioning, sizing, spacing, and decoration, and every other layout component (`Grid`, `Stack`, `Container`, `Section`) is a preset over `Box`.

---

## Responsive props

`Box` accepts **responsive props**. Any prop can be a single value, an array mapped to breakpoints in order, or an object keyed by breakpoint name (`sm`, `md`, `lg`, `xl`, `2xl`). The current viewport determines which value is applied.

### Array syntax
Values are applied in order of breakpoints:
```tsx
<Box width={['space-4', 'space-8', 'space-12']} />
```
- `sm`: `space-4`
- `md`: `space-8`
- `lg` and above: `space-12`

### Object syntax
Explicitly map each breakpoint:
```tsx
<Box width={{ sm: 'space-4', md: 'space-8', lg: 'space-12', xl: 'space-16' }} />
```

## Layout props

```md
| Prop | Description |
|------|-------------|
| `display` | CSS `display` — `block`, `flex`, `grid`, `inline`, etc. |
| `alignSelf` | Overrides parent's `alignItems` for this child. |
| `alignItems` | Aligns children along the cross axis. |
| `justifyContent` | Distributes children along the main axis. |
| `order` | Visual order inside flex or grid parent. |
| `flex` | Shorthand: `auto` (`flex: 1`) or `none` (`flex: 0`). |
| `flexDirection` | Main axis direction. |
| `flexWrap` | Wrap behavior. |
| `flexGrow` / `flexShrink` | Grow/shrink factors (0 or 1). |
| `flexBasis` | Initial main size — takes `Span` values (`auto`, `fill`, `half`, `third`, `quarter`). |
| `gridColumn` / `gridRow` | Grid placement — number (`span N`), `Span` keyword, or custom string. |
| `gridArea` | Named grid area. |
| `justifySelf` | Aligns box inside its grid cell (inline axis). |
```

---

## Sizing props

All sizing props accept `Spacing` tokens (`space-1` through `space-16`) or `Span` keywords (`auto`, `fill`, `half`, `third`, `quarter`).

- `width` / `height` — main dimensions
- `minWidth` / `maxWidth` — constraints

`Spacing` tokens map to `rem` values from your theme. `Span` keywords map to percentages.

---

## Spacing props

All spacing props accept `Spacing` tokens.

- `margin` / `padding` — all four sides
- `marginX` / `paddingX` — horizontal (overrides `margin`/`padding`)
- `marginY` / `paddingY` — vertical (overrides `margin`/`padding`)

---

## Decoration props

These apply surface treatments, borders, and shadows — all driven by your theme tokens.

- `surface` — `base`, `surface`, `elevated`, `overlay` → maps to `--bg-*`
- `appearance` — `flat` or `glass` (glass applies backdrop blur, translucent bg, and soft border)
- `border` — `subtle`, `default`, `strong` → maps to `--border-*`
- `borderWidth` — `none`, `thin`, `medium`, `bold`
- `borderRadius` — `none`, `sm`, `md`, `lg`, `xl`, `2xl`, `full` → maps to `--radius-*`
- `shadow` — `sm`, `md`, `lg`, `xl` → maps to `--shadow-*`

---

## Usage examples

### Basic container
```tsx
<Box padding="space-4" surface="elevated" borderRadius="md">
  Content goes here
</Box>
```

### Responsive grid child
```tsx
<Box gridColumn={['half', 'third', 'quarter']} padding="space-2">
  Responsive span
</Box>
```

### Glass card
```tsx
<Box appearance="glass" padding="space-6" borderRadius="2xl" shadow="lg">
  Frosted glass effect
</Box>
```

---

## Composition

`Box` is the foundation for `Grid`, `Stack`, `Container`, and `Section`. Those components are just `Box` with opinionated defaults and narrowed prop surfaces — they share the same responsive behavior and decoration system.

When you use `Box` as a child inside `Grid` or `Stack`, its flex/grid child props (`alignSelf`, `order`, `gridColumn`, etc.) are applied directly.
