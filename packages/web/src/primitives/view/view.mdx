# View

This is the fundamental layout component built around ***flexbox*** to be multi-purpose and open-ended. It natively provides two lightweight variants, `flat`, and `glass` with a handful of features to configure the layout surfaces.
<br/>



<Canvas
  withToolbar
  of={ ViewStories.ViewsLayered }
  layout='padded'
  source={{
    code: `
      import { SxStyles, Text, View, } from "@lucid-ui/web";

      export const GlassOverBaseViews = () => {
        return (
          <View sx={ styles.base }>
            <View
              variant={ variants.view.veneer }
              sx={ styles.veneer }
            >
              <Text>Timbo is in the party</Text>
            </View>
          </View>
        )
      };


      const variants = SxStyles.variants({
        view: {
          veneer: {
            name: 'glass',
            tone: 'neutral',
            intensity: 'subtle',
            elevation: 'level-1',
            blur: 'sm',
          },
        },
      });

      const styles = SxStyles.create({
        base: {
          justifyContent: 'center',
          width: 'fill',
          height: 'space-20',
          paddingHorizontal: 'space-8',
          backgroundColor: 'base',
          borderWidth: 'light',
          borderColor: 'subtle',
          borderRadius: 'xl',
        },
        veneer: {
          alignItems: 'center',
          width: 'half',
          marginHorizontal: 'auto',
          padding: 'space-3',
          borderRadius: '2xl',
        },
      });
    `
  }}
