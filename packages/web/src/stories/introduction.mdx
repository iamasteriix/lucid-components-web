# Getting Started

Lucid Design enables you to express yourself and give your audience a consistent and familiar experience across web and mobile.

Install the Lucid UI web components and start building.
```bash
npm install @lucid-ui/web
```


## Your first component
The `AppShell` accepts an optional `theme` prop for customization.
<br/>

### Theme System
Pass a partial object to `AppShell`. Only the tokens you provide are overridden; the rest fall back to the defaults.
```tsx
import { AppShell } from '@lucid-ui/web';

const theme = {
  colors: {
    primary: '#ff6b6b',
    accent: '#4ecdc4',
    error: '#f44336',
  },
  typography: {
    textBase: '1.125rem',
    weightBold: '800',
  },
  spacing: {
    space4: '1.25rem',
    space8: '2.5rem',
  },
};

const Root = () => {
  return (
    <AppShell theme={ theme }>
      <App/>
    </AppShell>
  );
}
```

Once you wrap `AppShell` around your app, you can use any component from the library. All layout, spacing, and visual props are token‑constrained, and you get autocomplete and type safety for every value.
