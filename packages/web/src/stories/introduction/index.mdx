# Getting Started

Lucid Design empowers you to express yourself and give your audience a consistent and familiar experience across web and mobile.

Install the Lucid UI web kit to get started.

```bash
npm install @lucid-ui/web @lucid-ui/core @lucid-ui/cli
```

To initialize your project with default font assets, run the following command in your terminal:

```bash
npx lucid-ui init --web
```

Once that's done, wrap your app inside the `AppLayoutView` component, and you are ready to go!

```tsx
import { AppLayoutView } from '@lucid-ui/web';
import { App } from './app.jsx';

const Root = () => {
  return (
    <AppLayoutView>
      <App/>
    </AppLayoutView>
  );
}
```
